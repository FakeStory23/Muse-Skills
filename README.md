# Katalog Skill Muse

**Bukan klaim kepemilikan.** Isi tiap skill tetap milik pembuatnya; katalog ini hanya menunjuk ke mana skill itu berasal. Hormati lisensi masing-masing skill sebelum memakai, menyalin, atau menyebarluaskan isinya.

## Cara pakai

1. Cari skill di [katalog.md](katalog.md) (tabel lengkap) atau per kategori di folder [kategori/](kategori/).
2. Baca deskripsi satu barisnya untuk tahu fungsinya.
3. Buka tautan **Sumber** untuk melihat repo asal, lisensi, dan cara instalasi resmi.
4. Skill yang terpasang ada di `~/workspace/custom-skills/<nama>/` — katalog ini tidak menyalin isi skill, jadi untuk memakai skill-nya buka folder tersebut.

## Catatan lisensi

- Kolom **Lisensi** diambil dari metadata skill (`INSTALL METADATA`, frontmatter `license:`, `UPSTREAM.md`, atau baris `Lisensi:` di SKILL.md). Bila tidak ditemukan, tertulis `-`.
- Lisensi yang paling umum di koleksi ini: MIT dan Apache-2.0 (bebas dipakai dengan syarat atribusi/ketentuan lisensi), serta CC BY 4.0 (wajib kredit pembuat).
- Sebagian skill berlisensi Proprietary atau tanpa lisensi tercatat — cek repo sumber sebelum memakai ulang.
- Deskripsi diterjemahkan/diringkas ke Bahasa Indonesia dari deskripsi asli skill (frontmatter atau paragraf pertama SKILL.md); nama teknis, path, dan perintah dipertahankan apa adanya.
